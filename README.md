AI-ассистент внутри Android. Не советует — делает. Собирает приложения, публикует релизы, ведёт соцсети. Без ПК и облаков.

## Установка

### Способ 1 — скачать APK (быстро)

Перейди в последний релиз и скачай termux-assistant-ai.apk. Установи на телефон.

### Способ 2 — через Termux (для продвинутых)

curl -fsSL https://raw.githubusercontent.com/CR4CODE/termux-assistant-ai-releases/main/bootstrap.sh | bash

Скрипт сам:
- проверит Termux
- поставит python, git, curl, termux-api
- скачает и откроет APK на установку

## Первый запуск

1. Открой приложение → Мастер настройки
2. Пройди шаги: Termux → Termux:API → Termux:Boot → Разрешения → Окружение → Сервер
3. Залогинься в DeepSeek

Мастер всё скачает и настроит сам.

## Что умеет

- AI-чат (DeepSeek в WebView)
- Голосовой ввод (плавающая draggable-кнопка)
- Терминал (bash-команды через Termux)
- Разработка (сборка APK прямо на телефоне)
- Соцсети (ВК, Telegram, VC.ru, Dev.to, Хабр)
- Очереди (отложенные публикации)
- Обновления (автопроверка через свой сервер)

## Требования

- Android 7.0+ (API 24)
- Termux (F-Droid)
- Termux:API (F-Droid)
- Termux:Boot (F-Droid, для автозапуска)
- ~500 МБ свободного места
