1. Общие сведения

Termux Assistant AI — открытое приложение для разработчиков и продвинутых пользователей Android, работающее в связке с Termux (эмулятором терминала Linux).

  • Разработчик: CR4CODE
  • Контакт: vk.com/termuxai · t.me/termux_assistant_ai
  • Исходный код: github.com/CR4CODE/termux-assistant-ai-releases

2. Какие данные обрабатывает приложение

Все данные обрабатываются исключительно локально на вашем устройстве. Приложение не имеет собственных серверов и не передаёт данные разработчику.

Локально могут сохраняться:

  • История команд и задач
  • Настройки приложения (тема, акцентный цвет, параметры Vibe)
  • Логи работы в /sdcard/ai-tasker/logs/
  • Собранные APK в /sdcard/Download/
  • Черновики постов в /sdcard/ai-tasker/{inbox,outbox}/

Эти данные остаются на устройстве, пока вы сами их не удалите.

3. Какие данные НЕ собираются

Приложение не собирает и не передаёт разработчику:

  • Персональные данные (имя, телефон, email)
  • Идентификаторы устройства (IMEI, Android ID, рекламные ID)
  • Геолокацию
  • Аналитику использования
  • Список установленных приложений

Приложение не содержит рекламы, трекеров, SDK аналитики и платежей.

4. Взаимодействие с внешними сервисами

4.1. DeepSeek (chat.deepseek.com)

При использовании AI-функций (генерация кода, постов, парсинг URL) приложение открывает WebView и взаимодействует с веб-интерфейсом DeepSeek по инициативе пользователя. Введённые запросы отправляются на серверы DeepSeek в соответствии с их политикой конфиденциальности.

Приложение не перехватывает и не сохраняет ваши диалоги с DeepSeek — только передаёт текст и читает ответ.

4.2. ВКонтакте (vk.com)

При публикации постов в сообщество ВКонтакте приложение вызывает VK API от вашего имени, используя ваш токен доступа, сохранённый локально в приватной папке Termux (~/.config/ai-tasker/vk.json).

4.3. Termux (локальное окружение)

Приложение отправляет задачи на локальный HTTP-сервер ai-tasker-server (127.0.0.1:8767), работающий внутри Termux на том же устройстве. Никакие данные не покидают устройство.

5. Разрешения и их назначение

Приложение запрашивает следующие разрешения:

  • SYSTEM_ALERT_WINDOW — оверлей обучающего туториала и диалога установки APK
  • POST_NOTIFICATIONS — уведомления о статусе задач
  • RECORD_AUDIO — голосовой ввод команд (только по действию пользователя)
  • READ/WRITE_EXTERNAL_STORAGE — чтение и запись APK, логов в /sdcard/ai-tasker/ и /sdcard/Download/
  • MANAGE_EXTERNAL_STORAGE — управление собранными APK в /sdcard/Download/
  • REQUEST_INSTALL_PACKAGES — установка APK, собранных пользователем в Termux
  • FOREGROUND_SERVICE — работа сервиса автономной сборки (Vibe)
  • ACCESSIBILITY_SERVICE (опционально) — вспомогательный сервис автоматизации, включается пользователем вручную

Все разрешения используются только для заявленной функциональности.

6. Безопасность

  • Все токены и ключи хранятся локально в приватной папке Termux с правами 600
  • Связь с локальным сервером идёт только через 127.0.0.1 (внутри устройства)
  • Открытый исходный код позволяет независимо проверить отсутствие скрытой передачи данных

7. Права пользователя

Вы в любой момент можете:

  • Удалить приложение и все его данные (включая файлы в /sdcard/ai-tasker/)
  • Отозвать разрешения в настройках Android
  • Очистить токены в ~/.config/ai-tasker/

8. Дети

Приложение не предназначено для детей младше 16 лет и не собирает данные о них.

9. Изменения политики
